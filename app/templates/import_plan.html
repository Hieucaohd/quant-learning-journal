Tạo JSON bằng ChatGPT

  1. Tải bộ file về máy. Prompt đã có sẵn tên khóa học và các bài cần tạo phần việc của bạn.
  2. Giải nén, tải cả 4 file lên ChatGPT, kèm đề cương khóa học nếu có.
  3. Dán prompt vào ChatGPT, điền các dòng còn trống ở cuối rồi gửi.
  4. Lưu JSON ChatGPT trả về và nhập ở khung bên trái.
